Connect once here to remember your speaker. Set your up/down counts and save them on this page.

Set up your two NFC tags
  1. On iPhone, open Shortcuts → Automation → + → NFC. Scan the tag and name it Bass up.
  2. Choose Run Immediately. Add an Open URLs action and paste the bass-up link copied above.
  3. Repeat with a second tag and the bass-down link.

Keep the phone unlocked for the first test. Scanning opens Bluefy. The page tries your remembered speaker and sends the saved count once, after connecting, then releases the connection. If no speaker is saved, the page opens the speaker chooser. If Bluefy requires a tap, choose “Choose speaker and continue”. Your bass request stays pending until you connect or press Release for puck.

For repeated scans, add Generate UUID in Shortcuts and append ?run= followed by its result to the copied link. Each scan then opens a fresh request.

Your original site's saved counts and permissions do not transfer to this copy. Default counts here are up 12 and down 13. An unstarted request waits for speaker selection. Once sending starts, interrupted commands are never replayed. Refreshing cancels the pending request.

Release other controllers before connecting.

Connection help

Use Bluefy on iPhone and allow Bluetooth access. Release the Mac controller and remove the physical puck batteries: the speaker accepts one controller at a time.

Keep this page open while sending commands. If the connection drops, remaining commands are cancelled. Tap Connect again; commands are never replayed automatically.

The numbers are command counts, not bass percentages. No calibration is needed. A confirmed command may have no audible effect at the speaker’s minimum or maximum.

No verified command for exiting pairing mode is available. There is no native Home Screen widget for this web version.
